# Changelog

## 1.1.0 - 2026-10-25

### Changed

- Raised the runtime baseline from Python 3.9 to Python 3.11.
- Added LangChain ChatOpenAI integration for OpenAI-compatible model providers.
- Upgraded LangGraph, FastAPI, Pydantic and Streamlit to pinned modern releases.
- Enabled a real FastMCP read-only database Tool Server.
- Moved blocking Text-to-SQL execution to FastAPI's worker thread pool.

## 1.0.0 - 2026-10-13

- Initial LangGraph-based Text-to-SQL release.
